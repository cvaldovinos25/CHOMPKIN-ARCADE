# CHOMPKIN ARCADE
Juego arcade de Halloween para celular y computador (HTML, CSS y JavaScript, sin servidor).
Personajes, laberinto y efectos originales: una calabaza hambrienta y 4 murciélagos con comportamientos distintos.

## Cómo se juega
- Desliza el dedo (o usa flechas / WASD) para mover la calabaza.
- Come todos los dulces; las pastillas brillantes asustan a los murciélagos y los puedes cazar.
- 3 vidas, vida extra a los 10.000 puntos, niveles cada vez más rápidos, túnel lateral, récord guardado en el dispositivo.
- Música: video de YouTube incrustado (si no carga, suena una música original por código).

## Publicar en GitHub Pages
1. Crea un repositorio (ej. `CHOMPKIN-ARCADE`) y sube todo el contenido.
2. Settings > Pages > Deploy from a branch > `main` / root.
3. Abre `https://TU-USUARIO.github.io/CHOMPKIN-ARCADE/` en el celular.
